Class class Profunctor p where
dimap :: ∀ a b c d. (a → b) → (c → d) → p b c → p a d

A Profunctor is a Functor from the pair category (Type^op, Type) to Type.

In other words, a Profunctor is a type constructor of two type arguments, which is contravariant in its first argument and covariant in its second argument.

The dimap function can be used to map functions over both arguments simultaneously.

A straightforward example of a profunctor is the function arrow (→).

Laws:

Identity
:
`dimap identity identity = identity`
Composition
:
`dimap f1 g1 <<< dimap f2 g2 = dimap (f1 >>> f2) (g1 <<< g2)`
Function lcmap :: ∀ a b c p. Profunctor p ⇒ (a → b) → p b c → p a c
lcmap a2b = dimap a2b identity

Map a function over the (contravariant) first type argument only.

Function rmap :: ∀ a b c p. Profunctor p ⇒ (b → c) → p a b → p a c
rmap b2c = dimap identity b2c

Map a function over the (covariant) second type argument only.

Function arr :: ∀ a b p. Category p ⇒ Profunctor p ⇒ (a → b) → p a b
arr f = rmap f identity

Lift a pure function into any Profunctor which is also a Category.

Function unwrapIso :: ∀ p t a. Profunctor p ⇒ Newtype t a ⇒ p t t → p a a
unwrapIso = dimap wrap unwrap
Function wrapIso ::
∀ p t a . Profunctor p ⇒ Newtype t a ⇒ (a → t) → p a a → p t t
wrapIso _ = dimap unwrap wrap
