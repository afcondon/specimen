FunctionsameDerivation::
∀ rule axiom .Eq rule⇒Eq axiom⇒Why rule axiom→Why rule axiom→Boolean
sameDerivation = case _, _ of
  Axiom a, Axiom b → a == b
  ByRule x, ByRule y → x.rule == y.rule && x.premises == y.premises && x.anchors == y.anchors
  Axiom _, ByRule _ → false
  ByRule _, Axiom _ → false

Derivation identity: what individuates a justification is its content — the rule and what it consumed — not source, which only records when the inference was first noticed. Rederiving the same conclusion from the same premises while processing a later event is the same derivation, and addFact must not collect it twice.

Typetype Fact claim rule axiom=
  { id :: FactId
  , claim :: claim
  , why :: Why rule axiom
  , alsoWhy :: Array (Why rule axiom)
  }

why is the primary justification — first derivation wins — and the only one the acyclicity guarantee covers: its premises point at strictly smaller ids. alsoWhy records every *other* way the claim was later rederived. Those may cite facts born after this one, so they are evidence of rederivability, not independently well-founded proofs — checking an alternative for well-founded support is ATMS work (extensions catalogue #7). Recording them now is what keeps that door open, and it is what lets a UI say "X-wing sees it too".

FunctionaddFact::
∀ residue claim rule axiom .Ord claim⇒Eq rule⇒Eq axiom⇒{ claim :: claim, why :: Why rule axiom }→KB residue claim rule axiom→KB residue claim rule axiom
addFact { claim, why } whole@(KB kb) = case Map.lookup claim kb.index of
  Just (FactId i) → case Array.index kb.facts i of
    Nothing → whole
    Just existing
      | sameDerivation why existing.why
          || Array.any (sameDerivation why) existing.alsoWhy → whole
      | otherwise →
          case Array.updateAt i (existing { alsoWhy = Array.snoc existing.alsoWhy why }) kb.facts of
            Nothing → whole
            Just updated → KB kb { facts = updated }
  Nothing →
    let
      id = FactId (Array.length kb.facts)
    in
      KB kb
        { facts = Array.snoc kb.facts { id, claim, why, alsoWhy: [] }
        , index = Map.insert claim id kb.index
        }

Record a claim. News gets a fresh fact; a claim already on the feed keeps its place and its primary justification, and the new derivation is appended to alsoWhy if it is genuinely different — so a claim rederivable six ways appears once, remembering all six.

importPreludeimportData.Arrayas ArrayimportData.Either(Either(..))importData.Foldable(foldl)importData.Map(Map)importData.Mapas MapimportData.Maybe(Maybe(..), fromMaybe)importData.Set(Set)importData.Setas SetimportData.Tuple(Tuple(..))
FunctionmaximumMatching::∀ a b. Ord a ⇒ Ord b ⇒ Map a (Set b) → Map b a
maximumMatching adjacency =
  foldl tryAugment Map.empty (Map.keys adjacency # Set.toUnfoldable :: Array a)
  where
  tryAugment matching a = case augment a Set.empty matching of
    Right matched → matched
    Left _ → matching

  -- Left: failed, with the visited set enlarged (threaded through the
  -- whole attempt — the essence of Kuhn's). Right: augmented matching.
  augment a visited matching =
    foldl step (Left visited) (neighbours a)
    where
    step (Right m) _ = Right m
    step (Left vis) b
      | Set.member b vis = Left vis
      | otherwise =
          let
            vis' = Set.insert b vis
          in
            case Map.lookup b matching of
              Nothing → Right (Map.insert b a matching)
              Just a' → case augment a' vis' matching of
                Right m' → Right (Map.insert b a m')
                Left vis'' → Left vis''

  neighbours a = fromMaybe [] (Set.toUnfoldable <$> Map.lookup a adjacency)

Maximum bipartite matching by Kuhn's augmenting paths, O(V·E) — right for the small dense graphs of a constraint house. Returns the matching right-to-left (each matched b with its a).

FunctionsccIds::∀ n. Ord n ⇒ Map n (Array n) → Map n Int
sccIds graph =
  let
    order = foldl (\st n → finishOrder n st) { seen: Set.empty, out: [] } nodes
    grouped = foldl assign { seen: Set.empty, comp: Map.empty, next: 0 }
      (Array.reverse order.out)
  in
    grouped.comp
  where
  nodes :: Array n
  nodes = Set.toUnfoldable (Map.keys graph)

  succsIn g n = fromMaybe [] (Map.lookup n g)

  -- first pass: DFS finish order on the forward graph
  finishOrder n st
    | Set.member n st.seen = st
    | otherwise =
        let
          descended = foldl (\s m → finishOrder m s)
            (st { seen = Set.insert n st.seen })
            (succsIn graph n)
        in
          descended { out = Array.snoc descended.out n }

  transposed :: Map n (Array n)
  transposed = foldl
    ( \acc (Tuple n succs) →
        foldl (\a m → Map.insertWith (<>) m [ n ] a) acc succs
    )
    Map.empty
    (Map.toUnfoldable graph :: Array (Tuple n (Array n)))

  -- second pass: sweep the reverse graph in reverse finish order
  assign st n
    | Set.member n st.seen = st
    | otherwise =
        let
          filled = fill n (st { seen = Set.insert n st.seen })
        in
          filled { next = st.next + 1 }
    where
    fill m s =
      foldl
        ( \acc m' →
            if Set.member m' acc.seen then acc
            else fill m' (acc { seen = Set.insert m' acc.seen })
        )
        (s { comp = Map.insert m st.next s.comp })
        (succsIn transposed m)

Strongly connected components (Kosaraju): each node mapped to a component id. Two nodes share an id iff they lie on a common cycle.

FunctionexplainFact::
∀ residue claim rule axiom .KB residue claim rule axiom→Fact claim rule axiom→DerivationDag claim rule axiom
explainFact kb root =
  let
    prefix = case root.id of FactId i → Array.take (i + 1) (facts kb)

    collect acc fact
      | Set.member fact.id acc.needed =
          { needed: foldl (flip Set.insert) acc.needed (premisesOf fact)
          , nodes: Array.cons fact acc.nodes
          , edges:
              map (\from → { from, to: fact.id }) (premisesOf fact) <> acc.edges
          }
      | otherwise = acc

    gathered = foldl collect
      { needed: Set.singleton root.id, nodes: [], edges: [] }
      (Array.reverse prefix)
  in
    { root: root.id, nodes: gathered.nodes, edges: gathered.edges }

Functionmain::Effect Unit
main = do
  let kb = foldl (learn engine) (emptyKB unit) observations
  case Array.findMap answer (facts kb) of
    Nothing → log "No slot works for everyone."
    Just slot → do
      log (slotName slot <> " — the only slot left standing. The other nineteen:")
      for_ (Array.filter (_ /= slot) allSlots) \s →
        for_ (factFor (Dead s) kb) \deadFact →
          log ("  " <> slotName s <> ": " <> joinWith "; " (reasons kb deadFact))
      let evidence = axiomsBehind (MeetAt slot) kb
      log ("Resting on " <> show (Array.length evidence) <> " calendar facts.")

    MeetAt slot → Just slot
    _ → Nothing
Functionreasons::MeetingKB → Fact Claim MeetingRule String → Array String
reasons kb fact =
  Array.cons fact.why fact.alsoWhy
    # Array.concatMap premisesOf
    # Array.mapMaybe (\id → factById id kb)
    # map describe
  where
  premisesOf = case _ of
    Axiom _ → []
    ByRule r → r.premises

    CantMake p _ → personName p <> " can't make it"
    RoomBusy _ → "the room is booked"
    _ → "eliminated"

  sourceText = case _ of
    Axiom src → " (" <> src <> ")"
    ByRule _ → ""

Functionconsistent::SudokuKB → Boolean
consistent kb = noDoublePlacement && noContradiction
  where
  placements = facts kb # Array.mapMaybe \fact → case fact.claim of
    Is c d → Just (c /\ d)
    Not _ _ → Nothing

  cells = map (\(c /\ _) → c) placements
  noDoublePlacement = Array.length (Array.nub cells) == Array.length cells

  v = view kb
  noContradiction = placements # Array.all \(c /\ d) →
    not (Set.member d (exclusionsAt v c))

No cell claims two digits, and no placement is also excluded. False only when the givens themselves were contradictory: the rules are monotone and sound, so garbage in is the only route to garbage out.

Functionengine::Engine Unit SudokuClaim SudokuRule Given
engine =
  { rules:
      [ rule SoleDigit do
          p ← placement
          other ← each (Array.filter (_ /= p.digit) allDigits)
          pure (Not p.cell other)
      , rule PeerElimination do
          p ← placement
          peer ← each (peersOf p.cell)
          pure (Not peer p.digit)
      , rule NakedSingle do
          c ← each allCells
          traverse_ (\d → absent (Is c d)) allDigits
          d ← each allDigits
          traverse_ (\other → require (Not c other)) (Array.filter (_ /= d) allDigits)
          pure (Is c d)
      , rule HiddenSingle do
          house ← each units
          d ← each allDigits
          traverse_ (\c → absent (Is c d)) house
          c ← each house
          traverse_ (\other → require (Not other d)) (Array.filter (_ /= c) house)
          pure (Is c d)
      ]
  , refine: \_ → identity
  }
  where
  placement = matches case _ of
    Is c d → Just { cell: c, digit: d }
    Not _ _ → Nothing

FunctionruleAlldifferent::SudokuKB → Array (Derivation SudokuClaim SudokuRule Given)
ruleAlldifferent kb = do
  let v = view kb
  house ← units
  let adjacency = Map.fromFoldable (house <#> \c → c /\ candidatesFor v c)
  let matching = maximumMatching adjacency
  -- an imperfect matching means the observations contradict; stay silent
  -- and let the client's consistency check tell that story
  guard (Map.size matching == 9)
  let
    matchedCell d = Map.lookup d matching

    -- alternating digraph: candidate edges cell→digit, matched digit→cell
    graph :: Map RNode (Array RNode)
    graph = Map.fromFoldable
      ( (house <#> \c → CellN c /\ map DigitN (Set.toUnfoldable (candidatesFor v c)))
          <> (allDigits <#> \d → DigitN d /\ Array.fromFoldable (CellN <$> matchedCell d))
      )

    comp = sccIds graph

    houseNots = house # Array.concatMap \c →
      allDigits
        # Array.filter (\d → not (Set.member d (candidatesFor v c)))
        # Array.concatMap (\d → cite kb (Not c d))
  c ← house
  d ← Set.toUnfoldable (candidatesFor v c)
  guard (matchedCell d /= Just c)
  guard (Map.lookup (CellN c) comp /= Map.lookup (DigitN d) comp)
  pure { claim: Not c d, rule: Alldifferent, premises: houseNots, anchors: [] }

Régin (1994), the canonical global propagator, as a prim rule: a house induces a bipartite cells↔digits graph; build a maximum matching; in the square perfect-matching case an unmatched candidate edge survives in SOME maximum matching iff its endpoints share a strongly connected component of the alternating digraph — everything else is eliminated. Constitutionally inexpressible in the eDSL; this is what the hatch is FOR.

Provenance is the house-level certificate: the elimination follows from exactly the Not facts that shaped the house's candidate graph, all cited. Sound but coarse — extracting the minimal Hall-set certificate from the SCC structure is the marked refinement.

Functioncompletions::
Int→Array Placement→{ grids :: Array Grid, exhaustive :: Boolean }
completions cap givens =
  let
    start = Map.fromFoldable (givens <#> \g → g.cell /\ g.digit)
    result = go { grids: [], truncated: false } start
  in
    { grids: result.grids, exhaustive: not result.truncated }
  where
  go acc assigned
    | Array.length acc.grids >= cap = acc { truncated = true }
    | otherwise = case bestOpenCell assigned of
        Nothing → acc { grids = Array.snoc acc.grids assigned }
        Just { cell, candidates } →
          foldl
            (\a d → go a (Map.insert cell d assigned))
            acc
            (Set.toUnfoldable candidates :: Array Digit)

  -- Most-constrained open cell first; an empty candidate set fails fast.
  bestOpenCell :: Grid → Maybe { cell :: Cell, candidates :: Set Digit }
  bestOpenCell assigned =
    allCells
      # Array.filter (\c → not (Map.member c assigned))
      # map (\c → { cell: c, candidates: candidatesAt assigned c })
      # minimumBy (comparing (Set.size <<< _.candidates))

  candidatesAt :: Grid → Cell → Set Digit
  candidatesAt assigned c =
    Set.difference (Set.fromFoldable allDigits)
      (Set.fromFoldable (Array.mapMaybe (\p → Map.lookup p assigned) (peersOf c)))

FunctionprintHunt::Effect Unit
printHunt = do
  let
    variants = do
      gridIx ← [ 0, 3, 7, 11 ]
      mult ← [ 37, 53 ]
      pure { gridIx, mult }
  results ← for variants \v → do
    let baseGrids = (completions (v.gridIx + 1) []).grids
    case Array.index baseGrids v.gridIx of
      Nothing → pure Nothing
      Just grid → do
        let
          full = Map.toUnfoldable grid <#> \(Tuple c d) → { cell: c, digit: d }
          order = Array.sortBy
            (comparing (\g → case g.cell of Cell i → (i * v.mult) `mod` 81))
            full
          keep acc g =
            let candidate = Array.filter (_ /= g) acc
            in if Array.length (completions 2 candidate).grids == 1 then candidate else acc
          minimal = foldl keep full order
          kb = solve minimal
          oracle = oracleFor (completions 2 minimal).grids
          theGap = gap oracle kb
        log
          ( "grid #" <> show v.gridIx <> " mult " <> show v.mult <> ": "
              <> show (Array.length minimal) <> " givens, singles "
              <> show (solvedCount kb) <> "/81, gap " <> show (Array.length theGap)
          )
        pure (if Array.null theGap then Nothing else Just { minimal, kb, oracle, theGap })
  case Array.head (Array.catMaybes results) of
    Nothing → log "no gap found in these variants — singles-complete throughout"
    Just found → do
      log ""
      log ("THE GAP EXHIBIT: " <> show (Array.length found.minimal) <> " givens")
      log (renderGrid \c → _.digit <$> Array.find (\g → g.cell == c) found.minimal)
      log
        ( "singles solve " <> show (solvedCount found.kb) <> "/81, unsound "
            <> show (Array.length (unsound found.oracle found.kb))
            <> ", GAP " <> show (Array.length found.theGap)
            <> " (placements: " <> show (Array.length (Array.filter isPlacement found.theGap)) <> ")"
        )
  where
  isPlacement = case _ of
    Is _ _ → true
    Not _ _ → false

Let the oracle hunt for the completeness-gap exhibit: take a valid grid (the Nth completion of the empty puzzle), greedily remove givens while the solution stays unique, and measure what the singles tier can and cannot see. Tries several base grids and removal orders; the cyclic pattern grid's subpuzzles all proved singles-complete, so irregular grids are where the gap hides.

    measure name puzzle = measureWith name engine puzzle

            <> ", unsound " <> show (Array.length (unsound oracle kb))
            <> ", gap " <> show (Array.length (gap oracle kb))
        )
  measure "diagonals   " diagonalsPuzzle
  measure "chain       " chainPuzzle
  measure "blankColumns" blankColumnsPuzzle
  measureWith "gap/singles " engine gapPuzzle

FunctionprintPage::Effect Unit
printPage = do
  let kb = solve chainPuzzle
  let
    deduced = facts kb # Array.filter \f → case f.claim, f.why of
      Is _ _, ByRule _ → true
      _, _ → false
    sized = deduced <#> \f → { f, n: Array.length (explainFact kb f).nodes }
    pick = case maximumBy (comparing _.n) (Array.filter (\s → s.n ⇐ 60) sized) of
      Just best → Just best.f
      Nothing → _.f <$> Array.head sized
  case pick of
    Nothing → log "no deduced placement to explain"
    Just f → log (page f kb)

The most interesting explainable placement: the deduced Is whose proof is largest while still labelable (≤ 60 facts).

Functiontranscript::Effect Unit
transcript = do
  let givens = diagonalsPuzzle
  let kb = solve givens
  log "puzzle:"
  log (renderGrid \c → _.digit <$> Array.find (\g → g.cell == c) givens)
  log ""
  log "solved:"
  log (renderGrid (valueAt kb))
  log ""
  log
    ( show (Array.length givens) <> " givens → "
        <> show (solvedCount kb)
        <> "/81 placed, "
        <> show (factCount kb)
        <> " facts on the feed, consistent: "
        <> show (consistent kb)
    )
  case Array.find isDeducedPlacement (facts kb) of
    Nothing → log "(no deduced placement found)"
    Just fact → do
      log ""
      log ("first deduced placement: " <> show fact.claim <> ", " <> whyName fact.why)
      case explain fact.claim kb of
        Nothing → pure unit
        Just dag → do
          let ground = axiomsBehind fact.claim kb
          log
            ( "its proof: " <> show (Array.length dag.nodes) <> " facts, "
                <> show (Array.length dag.edges)
                <> " premise edges, resting on "
                <> show (Array.length ground)
                <> " givens"
            )
  where
  isDeducedPlacement fact = case fact.claim, fact.why of
    Is _ _, ByRule _ → true
    _, _ → false

  whyName = case _ of
    Axiom _ → "a given"
    ByRule d → "by " <> show d.rule
