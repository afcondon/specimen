Surgical Instruments

Very sharp tools for very specific cuts. Code this dense is a standing temptation to keep writing JavaScript, just with an extraordinary amount of type noise — but where a polymorphic variant or a heterogeneous fold is genuinely needed, nothing else will do. Presented here as instruments: read slowly, use sparingly.
